# Runtime Environment (Vector MICROSAR Generated)

:::note[Origin: Vector-provided]
`SwProject/Source/Generated Runtime Environment Data` (`Rte.c/.h`, component headers, `Rte.html` wiring report, `Rte.oil`) is generated by the Vector MICROSAR Runtime Environment Generator from the DaVinci configuration. Do not edit by hand.
:::

## What it does

The Runtime Environment connects every Application Software and Sensor/Actuator software component: port-based communication, runnable scheduling, mode handling and measurement hooks. Each component's `tools/contract/*` headers in its own folder are local copies of the same generated contracts for offline builds and unit tests.

## Key artefacts

- `Rte.c`, `Rte.h`, `Rte_Cbk.h`, `Rte_Cfg.h`, `Rte_Hook.h` — generated middleware.
- `Components/` — per-component generated headers.
- `Rte.html` / `Rte.a2l` — wiring report and measurement description.
- `Source/Generated Configuration Data/Ap_*_Cfg.h`, `CalConstants.*` — per-component configuration and calibration.
